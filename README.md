# DataStory Studio — story data

Public data for the [DataStory Studio](https://apps.apple.com/) iOS app. Every
file here is served straight from this branch by `raw.githubusercontent.com`, so
pushing to `main` is the whole deploy.

Nothing here is generated by hand. Edit the datasets in the app repo under
`DataStoryStudio/Resources/`, run `Tools/gen_manifest.py`, and copy the contents
of `remote/` into this repository.

## What the app does with this

1. On launch — at most once every six hours — it fetches `manifest.json`.
2. If `version` has not moved since the last check, it stops there. That request
   is about 1.4 KB.
3. If it has, it downloads only the datasets whose own `version` has changed.
4. Those are cached on the device and layered over the copies shipped inside the
   app.

## manifest.json

```json
{
  "schema": 1,
  "version": 7,
  "datasets": [
    { "id": "gdp", "version": 3, "path": "Race-gdp.json", "bytes": 18244 }
  ]
}
```

| Field | Meaning |
|---|---|
| `schema` | Format version of this file. A build ignores a catalog whose schema is newer than it understands, so new fields can be added without breaking installed apps. |
| `version` | Bumped whenever any dataset changes. Lets the app skip everything else when nothing has moved. |
| `datasets[].id` | Must match the `id` inside the dataset file. A mismatch is rejected. |
| `datasets[].version` | Bumped only for datasets whose contents actually changed, so one edit does not re-download all nine. |
| `datasets[].path` | Relative to this file. |
| `datasets[].bytes` | Exact file size. A download that does not match is discarded — truncated responses are the common failure and they are silent. |

`_fingerprints` is publishing bookkeeping. The app's decoder ignores it.

## Rules the app enforces

- **This data can add or update a story. It can never remove one.** The copies
  inside the app are the floor, so a bad push means "no new data", never "the
  app is empty".
- Downloaded files are decoded and sanity-checked *before* being cached. A file
  that will not parse, has the wrong `id`, or has fewer than two entities never
  reaches the device's library.
- HTTPS only.
- Every failure is silent. No network, repo renamed, GitHub down — the app opens
  on its bundled stories and says nothing.

## Publishing an update

```sh
# in the app repo
python3 Tools/gen_manifest.py

# then, in this repo
cp -R /path/to/DataStoryStudio/remote/. .
git add -A && git commit -m "Update GDP through 2026" && git push
```

Version numbers are derived from file fingerprints, so re-running the generator
without changing anything bumps nothing and costs users no downloads.

Allow about five minutes for the `raw.githubusercontent.com` CDN to catch up.

## Sources

Figures come from the published sources credited inside each dataset's
`source` and `sourceURL` fields. Years between anchor points are interpolated,
which is how animated charts of this kind are normally built — treat them as
illustrative rather than exact.
